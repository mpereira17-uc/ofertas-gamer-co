¿Corre en mi PC?

Mínimos

  • Requiere un procesador y un sistema operativo de 64 bits
  • SO *: Windows 7 64-bit
  • Procesador: AMD or Intel, 3 GHz (AMD A10 7850K, Intel i3-2000)
  • Memoria: 8 GB de RAM
  • Gráficos: AMD/NVIDIA dedicated GPU, 2GB dedicated VRAM (Radeon HD 7870, Geforce GTX 750)
  • DirectX: Versión 11
  • Almacenamiento: 16 GB de espacio disponible

Recomendados

  • Requiere un procesador y un sistema operativo de 64 bits
  • SO: Windows 10 64-bit
  • Procesador: AMD or Intel, 3.3 GHz (AMD FX 8300, Intel i5 3000)
  • Memoria: 16 GB de RAM
  • Gráficos: AMD/NVIDIA dedicated GPU, 4GB dedicated VRAM (Radeon R9 380, Geforce GTX 960)
