¿Corre en mi PC?

Mínimos

  • Requiere un procesador y un sistema operativo de 64 bits
  • SO: Windows 10
  • Procesador: x64 Quad Core
  • Memoria: 4 GB de RAM
  • Gráficos: Dedicated graphics card (not onboard) with >= 1GB RAM
  • DirectX: Versión 11
  • Almacenamiento: 3 GB de espacio disponible

Recomendados

  • Requiere un procesador y un sistema operativo de 64 bits
  • SO: Windows 10
  • Procesador: x64 Quad Core
  • Memoria: 8 GB de RAM
